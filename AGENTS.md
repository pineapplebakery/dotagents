# Agent Instructions

## Skill Management

- Track only skills created and maintained in this repository with Git.
- Do not commit third-party open-source skills directly. Download and install them through `install.sh`.
- Do not use `npx` to obtain open-source skills. Download them from their source repositories with `curl` or `wget`.
- Add open-source skill directories to `.gitignore` so downloaded files are not committed accidentally.
- When installing or updating an open-source skill, review its source and contents. If a security concern is found, accurately notify the user of the affected skill and file, the concerning behavior, its potential impact, and the verified evidence. Clearly distinguish speculation from verified facts.
